把考编打卡装到你的设备

像 App 一样全屏使用 · 图标在桌面 · 离线也能刷题

📲 一次安装，长期使用

添加到主屏幕后，打开就是全屏应用，没有浏览器地址栏，刷题更专注。题目数据会缓存在本机，断网也能做已经加载过的题。

🤖 安卓
🍎 iPhone / iPad
💻 Windows 电脑

安卓手机安装 推荐 Chrome / Edge

1用 Chrome 或 Edge 浏览器打开本系统的网址（微信/QQ 内置浏览器不支持安装）。
2点浏览器右上角三个点菜单。
3选择 「安装应用」 或 「添加到主屏幕」。
4确认后，桌面就会出现「考编打卡」图标，点开即可全屏使用。
💡 部分安卓浏览器菜单里叫「添加到主屏幕」或「安装到桌面」，效果一样。找不到时换 Chrome 浏览器再试。
—

iPhone / iPad 安装 必须用 Safari

1用 Safari 浏览器打开本系统网址（微信里打开请先点右上角「…」→「在 Safari 中打开」）。
2点 Safari 底部中间的分享按钮（方框带向上箭头 ⬆️）。
3在菜单里下滑，找到 「添加到主屏幕」。
4点右上角「添加」，桌面即出现图标，点开全屏使用。
💡 iOS 不能用 Chrome 安装，必须用 Safari。添加后从桌面图标打开，才有全屏效果；从 Safari 里打开仍带地址栏。
—

Windows 电脑 · 两种用法

📦方式一：exe 桌面版（推荐）下载 Windows 安装包，双击安装即可。题库已内置，完全离线可用，无需联网。
🌐方式二：浏览器安装为应用用 Edge 或 Chrome 打开网址，点地址栏右侧的「安装」图标，即可生成桌面快捷方式，独立窗口运行。
💡 exe 版适合没有网络或想要独立软件的用户；浏览器版更新最及时（题库自动同步最新版）。两者数据不互通，可用「我的 → 同步码」转移进度。
